## Short proposal for a diagnosed API repair

My delivery would include:

1. a regression script that fails against the current implementation;
2. the smallest safe code changes needed to satisfy the reference outputs;
3. a pull request with passing tests and a concise defect-to-fix report;
4. local or staging verification using the access you provide.

Here is a truthful before/after demo of the same workflow: a broken FastAPI service, six repaired defects, and an executable acceptance suite. I will not use production customer data or make unapproved destructive changes.

I use AI-assisted development and will keep the process transparent. If the repository and reference exports match the description, I can start with a funded diagnostic milestone and confirm the final scope before implementation.

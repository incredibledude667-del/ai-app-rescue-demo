# Fixed-scope AI app rescue

## Plain-English promise

Send a repository, reproducible bugs, and the expected result. Receive a tested pull request, a before/after evidence report, and clear deployment instructions within 72 hours.

## Good fit

- AI-built or inherited web app with reproducible backend/API failures;
- FastAPI, Python, Node.js, Next.js, or Supabase codebase;
- a staging environment or local reproduction path;
- acceptance criteria that can be turned into automated tests.

## Not accepted without a separate safety review

- unscoped production access;
- changes that move real money or delete customer data;
- penetration testing or a claim of security certification;
- work that forbids AI-assisted development;
- CAPTCHA, access-control, or terms-of-service bypasses.

## Packages

### Diagnostic pilot — $99

- reproduce up to two reported defects;
- write failing acceptance tests;
- return a fixed quote and implementation plan;
- credited in full if the rescue proceeds.

### 72-hour rescue — $500–700

- repair one bounded workflow or up to seven related defects;
- add regression tests and CI verification;
- provide a pull request, incident report, and handoff commands;
- one revision against the agreed acceptance criteria.

### Stabilization sprint — $900–1,200

- repair multiple related workflows;
- add smoke/regression coverage;
- staging deployment and rollback notes when access is supplied;
- two revisions against the agreed acceptance criteria.

## Working rules

- Client funds the milestone before repository access is shared.
- AI-assisted development is disclosed before the contract starts.
- Client confirms they are authorized to share the repository and test data.
- Secrets stay in the client's secret manager; sample or staging data is preferred.
- Delivery is judged against written acceptance criteria, not vague promises.
